# Ativos do projeto

Coloque os originais nas pastas abaixo. A aplicação deve usar derivados selecionados e otimizados, preservando estes arquivos.

| Pasta | O que colocar |
|---|---|
| `brand/` | Manual de identidade, logos oficiais, versões claras/escuras, paleta, tipografia e fontes disponíveis |
| `executives/sabrina-ferreira/` | Retrato real de Sabrina, preferencialmente em alta resolução, e eventuais orientações de recorte |
| `clients/` | Logos oficiais de clientes autorizados para a apresentação |
| `operations/` | Fotografias reais de unidades, equipe, atendimento e equipamentos |
| `product/` | Capturas reais de sistemas, se houver material liberado para uso comercial |
| `certifications/` | Selos, certificados e documentação com titularidade, escopo e validade |
| `motion/` | Referências visuais e materiais de apoio para animações |

## Prioridade de fornecimento

Identidade visual e retrato de Sabrina são os ativos com maior impacto no primeiro layout. Logos de clientes e imagens de operação ajudam a tornar a experiência própria da CRED.

## Instruções para o Claude

- Inspecionar formatos, resolução e proporção antes de escolher.
- Usar a versão correta de logo para cada fundo, sem distorcer ou recriar.
- Não publicar esta pasta inteira. Ela pode conter fontes, manuais, documentos e originais desnecessários ao visitante.
- Guardar derivados em `public/media/` ou equivalente da stack.
- Não usar certificado como imagem decorativa sem saber a quem se refere.
- Não redesenhar logo de cliente nem gerar foto que pareça retrato real de Sabrina.
- Na ausência de fotografia, resolver com composição tipográfica. Registrar a falta em vez de inventar uma pessoa.
- Não rotular imagens genéricas como unidades ou equipe da CRED.
